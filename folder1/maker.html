Question Maker

For the website owner. Make questions here, then paste the code into the data file. This page does not change your website by itself.

How it works

  1. Fill the form below (one question) or paste many rows from Google Sheets / Excel.
  2. Press Create code, then Copy code.
  3. Open data/questions.js (or data/current-affairs.js for current affairs) in Notepad.
  4. Paste just above the line // ===== ADD NEW QUESTIONS ABOVE THIS LINE ===== and save.
  5. Upload the whole website folder to Cloudflare again (see the guide).
