Sample Input & Output Devices questions with answers

Q1. Which of the following is an input device?

निम्न में से कौन-सा इनपुट डिवाइस है?

  1. Monitor
  2. Printer
  3. Keyboard
  4. Speaker
Answer: Keyboard. A keyboard sends data into the computer. Monitor, printer and speaker are output devices.
कीबोर्ड कंप्यूटर में डेटा भेजता है। मॉनिटर, प्रिंटर और स्पीकर आउटपुट डिवाइस हैं।

Q2. The flat touch-sensitive pad on a laptop that replaces the mouse is called the:

लैपटॉप पर माउस की जगह लेने वाला समतल स्पर्श-संवेदी पैड क्या कहलाता है?

  1. Speaker
  2. Webcam
  3. Port
  4. Touchpad (trackpad)
Answer: Touchpad (trackpad). You slide a finger on it to move the pointer.
पॉइंटर हिलाने के लिए उस पर उँगली सरकाते हैं।

Q3. A modem is an example of a device that works as:

मॉडेम किस रूप में काम करने वाले उपकरण का उदाहरण है?

  1. Input device only
  2. Both input and output (communication) device
  3. Storage device only
  4. Output device only
Answer: Both input and output (communication) device. It sends data out and brings data in.
यह डेटा बाहर भेजता और भीतर लाता है।

Q4. Which of these is a non-impact printer?

इनमें से कौन-सा नॉन-इम्पैक्ट प्रिंटर है?

  1. Daisy wheel printer
  2. Laser printer
  3. Dot matrix printer
  4. Line printer (drum type)
Answer: Laser printer. Non-impact printers are quieter.
नॉन-इम्पैक्ट प्रिंटर शांत होते हैं।

Q5. Typing without looking at the keyboard, using all fingers, is called:

बिना कीबोर्ड देखे सभी उँगलियों से टाइप करना क्या कहलाता है?

  1. Touch typing
  2. Scanning
  3. Hunt and peck typing
  4. Voice typing
Answer: Touch typing. It makes typing faster and more accurate.
इससे टाइपिंग तेज़ और अधिक सही होती है।

Q6. A large touch-enabled board used in classrooms in place of a blackboard is a:

कक्षाओं में ब्लैकबोर्ड की जगह प्रयुक्त बड़ा टच-सक्षम बोर्ड क्या है?

  1. Plotter
  2. Smart board (interactive whiteboard)
  3. Modem
  4. Joystick
Answer: Smart board (interactive whiteboard). It connects to a computer and projector.
यह कंप्यूटर और प्रोजेक्टर से जुड़ता है।

Q7. A projector is mainly used to:

प्रोजेक्टर का मुख्य उपयोग क्या है?

  1. Show the computer screen on a large wall or screen
  2. Store files
  3. Scan photographs
  4. Print documents
Answer: Show the computer screen on a large wall or screen. It is common in classrooms and meetings.
यह कक्षाओं और बैठकों में आम है।

Q8. RFID tags, used in FASTag on vehicles, are read:

वाहनों पर लगे FASTag जैसे RFID टैग कैसे पढ़े जाते हैं?

  1. By a floppy drive
  2. By radio waves from a reader
  3. By a keyboard
  4. By a microphone
Answer: By radio waves from a reader. FASTag lets vehicles pay tolls without stopping.
FASTag से वाहन रुके बिना टोल दे सकते हैं।

Q9. The part of a laser printer on which the image is first formed with static electricity is the:

लेज़र प्रिंटर का वह भाग जिस पर स्थैतिक बिजली से पहले चित्र बनता है, कौन-सा है?

  1. Platen
  2. Ribbon
  3. Drum
  4. Nozzle
Answer: Drum. The drum attracts toner where the laser touched it.
लेज़र जहाँ छूता है, वहाँ ड्रम टोनर खींचता है।

Q10. Printers that hit the paper to make marks are called:

जो प्रिंटर कागज़ पर चोट करके निशान बनाते हैं, वे क्या कहलाते हैं?

  1. Wireless printers
  2. Thermal scanners
  3. Non-impact printers
  4. Impact printers
Answer: Impact printers. Dot matrix and daisy wheel printers are examples.
डॉट मैट्रिक्स और डेज़ी व्हील प्रिंटर उदाहरण हैं।
