Sample Operating System Basics questions with answers

Q1. Which of the following is an operating system?

निम्न में से कौन-सा ऑपरेटिंग सिस्टम है?

  1. Windows
  2. Paint
  3. MS Word
  4. Google Chrome
Answer: Windows. Windows is an operating system; Chrome, Word and Paint are applications.
विंडोज़ ऑपरेटिंग सिस्टम है; क्रोम, वर्ड और पेंट एप्लिकेशन हैं।

Q2. A small picture on the screen that represents a program, file or folder is called an:

स्क्रीन पर प्रोग्राम, फ़ाइल या फ़ोल्डर दर्शाने वाला छोटा चित्र क्या कहलाता है?

  1. Window
  2. Icon
  3. Cursor
  4. Pixel
Answer: Icon. Double-clicking an icon opens it.
आइकन पर डबल-क्लिक करने से वह खुलता है।

Q3. An OS that allows many users to use the same computer's resources at the same time, as in UNIX, is:

जो OS कई उपयोगकर्ताओं को एक ही कंप्यूटर के संसाधन एक साथ उपयोग करने देता है, जैसे UNIX, वह कैसा है?

  1. Batch-only
  2. Multi-user
  3. Single-tasking
  4. Single-user
Answer: Multi-user. Each user has a separate account and terminal.
हर उपयोगकर्ता का अलग खाता और टर्मिनल होता है।

Q4. The GNU Project, which gave many free tools used with Linux, was started by:

GNU परियोजना, जिसने लिनक्स के साथ प्रयुक्त कई मुफ़्त टूल दिए, किसने शुरू की?

  1. Bill Gates
  2. Tim Cook
  3. Richard Stallman
  4. Linus Torvalds
Answer: Richard Stallman. He also founded the Free Software Foundation.
उन्होंने फ़्री सॉफ़्टवेयर फ़ाउंडेशन भी स्थापित किया।

Q5. When a program stops responding and the computer freezes, it is said to have:

जब कोई प्रोग्राम प्रतिक्रिया देना बंद कर दे और कंप्यूटर रुक जाए, तो कहा जाता है कि वह:

  1. Booted
  2. Hibernated
  3. Formatted
  4. Hung (crashed)
Answer: Hung (crashed). End the task from Task Manager to recover.
पुनः ठीक करने के लिए टास्क मैनेजर से कार्य समाप्त करें।

Q6. The famous blue error screen shown by Windows when a serious system error occurs is commonly called the:

गंभीर सिस्टम त्रुटि होने पर विंडोज़ द्वारा दिखाई जाने वाली प्रसिद्ध नीली त्रुटि स्क्रीन को आम तौर पर क्या कहते हैं?

  1. Wallpaper error
  2. Safe Screen
  3. Blue Screen of Death (BSOD)
  4. Blue Desktop
Answer: Blue Screen of Death (BSOD). It usually comes from driver or hardware faults.
यह प्रायः ड्राइवर या हार्डवेयर की खराबी से आती है।

Q7. Pressing Shift + Delete on a file in Windows:

विंडोज़ में किसी फ़ाइल पर Shift + Delete दबाने से:

  1. Renames it
  2. Opens it
  3. Copies it
  4. Deletes it permanently without sending it to the Recycle Bin
Answer: Deletes it permanently without sending it to the Recycle Bin. Use it with care.
इसे सावधानी से उपयोग करें।

Q8. Small programs that run quietly in the background in Windows, such as the print spooler, are called:

विंडोज़ में पृष्ठभूमि में चुपचाप चलने वाले छोटे प्रोग्राम, जैसे प्रिंट स्पूलर, क्या कहलाते हैं?

  1. Wallpapers
  2. Icons
  3. Shortcuts
  4. Services
Answer: Services. In Linux they are called daemons.
लिनक्स में इन्हें डेमन कहते हैं।

Q9. Processes P1, P2, P3 arrive at time 0 (in this order) with burst times P1 = 6, P2 = 3, P3 = 4 (ms). Using Round Robin with a time quantum of 2 ms, what is the average waiting time?

प्रक्रियाएँ P1, P2, P3 समय 0 पर (इसी क्रम में) आती हैं; बर्स्ट समय P1 = 6, P2 = 3, P3 = 4 (ms) हैं। 2 ms टाइम क्वांटम वाले राउंड रॉबिन में औसत प्रतीक्षा समय कितना है?

  1. 6.67 ms
  2. 9.67 ms
  3. 5 ms
  4. 3.33 ms
Answer: 6.67 ms. Waiting time = finish time − burst time: 7, 6, 7. Average = 20 ÷ 3 = 6.67 ms.
प्रतीक्षा समय = समाप्ति समय − बर्स्ट समय: 7, 6, 7। औसत = 20 ÷ 3 = 6.67 ms।

Q10. A text file containing a list of DOS/Windows commands to be run one after another has the extension:

एक के बाद एक चलाए जाने वाले DOS/विंडोज़ आदेशों की सूची वाली टेक्स्ट फ़ाइल का एक्सटेंशन क्या होता है?

  1. .bat
  2. .mp3
  3. .jpg
  4. .exe
Answer: .bat. It is called a batch file.
इसे बैच फ़ाइल कहते हैं।
