Sample Sandhi questions with answers

Q1. Which sandhi is in the word 'महोत्सव'?

'महोत्सव' शब्द में कौन-सी संधि है?

  1. अयादि स्वर संधि
  2. व्यंजन संधि
  3. गुण स्वर संधि
  4. यण स्वर संधि
Answer: गुण स्वर संधि. महोत्सव = महा + उत्सव, so it is guna (vowel) sandhi.
महोत्सव = महा + उत्सव, अतः यह गुण स्वर संधि है।

Q2. Which sandhi is in the word 'सुरेश'?

'सुरेश' शब्द में कौन-सी संधि है?

  1. गुण स्वर संधि
  2. वृद्धि स्वर संधि
  3. व्यंजन संधि
  4. यण स्वर संधि
Answer: गुण स्वर संधि. सुरेश = सुर + ईश, so it is guna (vowel) sandhi.
सुरेश = सुर + ईश, अतः यह गुण स्वर संधि है।

Q3. Which sandhi is in the word 'इत्यादि'?

  2. यण स्वर संधि

  4. विसर्ग संधि
Answer: यण स्वर संधि. इत्यादि = इति + आदि, so it is yan (vowel) sandhi.
इत्यादि = इति + आदि, अतः यह यण स्वर संधि है।

Q4. Choose the correct sandhi-viched (संधि-विच्छेद) of 'नयन'.

'नयन' का सही संधि-विच्छेद चुनें।

  1. नेा + आन
  2. ने + आन
  3. नेा + अन
  4. ने + अन
Answer: ने + अन. नयन = ने + अन — ayadi (vowel) sandhi.
नयन = ने + अन (अयादि स्वर संधि).

Q5. Which sandhi is in the word 'मनोबल'?

'मनोबल' शब्द में कौन-सी संधि है?

  4. विसर्ग संधि
Answer: विसर्ग संधि. मनोबल = मनः + बल, so it is visarg sandhi.
मनोबल = मनः + बल, अतः यह विसर्ग संधि है।

Answer: व्यंजन संधि. दिग्गज = दिक् + गज, so it is vyanjan (consonant) sandhi.
दिग्गज = दिक् + गज, अतः यह व्यंजन संधि है।
