Sample Syllogism questions with answers

Q1. Statements: All cats are animals. All animals are living beings. Which conclusion definitely follows?

कथन: सभी बिल्लियाँ जानवर हैं। सभी जानवर सजीव हैं। कौन-सा निष्कर्ष निश्चित रूप से निकलता है?

  1. All cats are living beings
  2. All living beings are cats
  3. No cat is a living being
  4. Some animals are not cats
Answer: All cats are living beings. Cats are inside animals, and animals are inside living beings, so all cats are living beings. The other options cannot be concluded for sure.
बिल्लियाँ जानवरों के अंदर हैं और जानवर सजीवों के अंदर हैं, अतः सभी बिल्लियाँ सजीव हैं। अन्य विकल्प निश्चित रूप से नहीं निकलते।

  1. No pens are apples.
  2. Some lakes are not pens.
  3. Some lakes are apples.
  4. Some pens are lakes.
Answer: Some pens are lakes.. Draw the possible Venn diagrams for the statements. Only this conclusion is true in every possible diagram.

Answer: Only conclusion I follows. Draw the possible Venn diagrams for both statements. Conclusion I must be true; conclusion II is not certain.
