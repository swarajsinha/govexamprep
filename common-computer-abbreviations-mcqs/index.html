Sample Common Computer Abbreviations questions with answers

Q1. What is the full form of URL?

URL का पूर्ण रूप क्या है?

  1. Uniform Resource Locator
  2. Universal Resource Link
  3. Uniform Reference Link
  4. Universal Record Locator
Answer: Uniform Resource Locator. URL = Uniform Resource Locator, the address of a web page.
URL = Uniform Resource Locator, यह किसी वेब पेज का पता होता है।

Q2. Third-generation computers used:

तीसरी पीढ़ी के कंप्यूटरों में किसका उपयोग हुआ?

  1. VLSI microprocessors
  2. AI chips
  3. Vacuum tubes
  4. ICs (Integrated Circuits)
Answer: ICs (Integrated Circuits). 1st: vacuum tubes; 2nd: transistors; 3rd: ICs; 4th: VLSI microprocessors.
पहली: वैक्यूम ट्यूब; दूसरी: ट्रांजिस्टर; तीसरी: IC; चौथी: VLSI माइक्रोप्रोसेसर।

Q3. What is the full form of KYC?

KYC का पूर्ण रूप क्या है?

  1. Know Your Customer
  2. Keep Your Card
  3. Key Your Code
  4. Know Your Credit
Answer: Know Your Customer. KYC = Know Your Customer.
KYC = Know Your Customer।

Q4. In PaaS, the letter P stands for:

PaaS में P का अर्थ है:

  1. Private
  2. Program
  3. Protocol
  4. Platform
Answer: Platform. PaaS = Platform as a Service.
PaaS = प्लेटफ़ॉर्म ऐज़ अ सर्विस।

Q5. What is the full form of VLSI?

VLSI का पूर्ण रूप क्या है?

  1. Very Low Speed Integration
  2. Virtual Large Scale Integration
  3. Very Large System Interface
  4. Very Large Scale Integration
Answer: Very Large Scale Integration. VLSI = Very Large Scale Integration. VLSI chips are used in fourth- and fifth-generation computers.
VLSI = Very Large Scale Integration। VLSI चिप चौथी और पाँचवीं पीढ़ी के कंप्यूटरों में उपयोग होती हैं।

Q6. DPI stands for:

DPI का पूरा नाम क्या है?

  1. Digits Per Inch
  2. Data Per Inch
  3. Display Per Inch
  4. Dots Per Inch
Answer: Dots Per Inch. DPI = Dots Per Inch. It measures printer and scanner resolution.
DPI = Dots Per Inch। यह प्रिंटर और स्कैनर का रेज़ोल्यूशन मापता है।

Q7. In computer terms, GSM means:

कंप्यूटर में GSM का अर्थ है:

  1. General System for Mobile
  2. Global Signal Mobile
  3. Global Service for Messages
  4. Global System for Mobile communications
Answer: Global System for Mobile communications. GSM = Global System for Mobile communications.
GSM = Global System for Mobile communications।

Q8. What is the full form of C-DAC?

C-DAC का पूर्ण रूप क्या है?

  1. Central Department of Advanced Computing
  2. Centre for Digital Advanced Computers
  3. Centre for Development of Advanced Computing
  4. Council for Development of Advanced Computing
Answer: Centre for Development of Advanced Computing. C-DAC = Centre for Development of Advanced Computing. It built PARAM, India's first supercomputer (1991).
C-DAC = Centre for Development of Advanced Computing। इसने भारत का पहला सुपरकंप्यूटर PARAM (1991) बनाया।

Q9. What is the full form of Wi-Fi (as commonly expanded in exams)?

Wi-Fi (as commonly expanded in exams) का पूर्ण रूप क्या है?

  1. Wireless Fidelity
  2. Wired Fidelity
  3. Wide Fidelity
  4. Wireless Filter
Answer: Wireless Fidelity. Wi-Fi (as commonly expanded in exams) = Wireless Fidelity. Wi-Fi is a brand name; exams usually expand it as Wireless Fidelity.
Wi-Fi (as commonly expanded in exams) = Wireless Fidelity। Wi-Fi एक ब्रांड नाम है; परीक्षाओं में इसे प्रायः वायरलेस फ़िडेलिटी लिखा जाता है।

Q10. In computer terms, ASCII means:

कंप्यूटर में ASCII का अर्थ है:

  1. American Standard Code for Internet Information
  2. American Standard Code for Information Interchange
  3. American System Code for Information Interchange
  4. Asian Standard Code for Information Interchange
Answer: American Standard Code for Information Interchange. ASCII = American Standard Code for Information Interchange. Standard ASCII uses 7 bits (128 characters).
ASCII = American Standard Code for Information Interchange। मानक ASCII 7 बिट (128 अक्षर) उपयोग करता है।
