ऑपरेटिंग सिस्टम की मूल बातें – हिंदी में निःशुल्क अभ्यास प्रश्न

ऑपरेटिंग सिस्टम की मूल बातें कंप्यूटर जागरूकता का महत्वपूर्ण टॉपिक है, जो SSC, रेलवे, बैंकिंग और अन्य सरकारी परीक्षाओं में पूछा जाता है। यहाँ 150 निःशुल्क अभ्यास प्रश्न हिंदी और अंग्रेज़ी में हैं, सही उत्तर और व्याख्या के साथ, और छोटे रिवीज़न नोट्स भी।

छोटे नोट्स पढ़ेंव्याख्या के साथ अभ्यास10 प्रश्नों की क्विज़समयबद्ध टॉपिक टेस्ट

वेबसाइट खुलने पर ऊपर हिंदी बटन दबाएँ, सभी प्रश्न और व्याख्या हिंदी में दिखेंगी।

ऑपरेटिंग सिस्टम की मूल बातें – उत्तर सहित नमूना प्रश्न

प्र1. विंडोज़ चालू होने के बाद दिखने वाली मुख्य स्क्रीन क्या कहलाती है?

  1. केवल टास्कबार
  2. डेस्कटॉप
  3. ब्राउज़र
  4. फ़ोल्डर
उत्तर: डेस्कटॉप। डेस्कटॉप आइकन वाली मुख्य स्क्रीन है।

प्र2. लंबे समय से प्रतीक्षा कर रहे प्रोसेस की प्राथमिकता धीरे-धीरे बढ़ाना क्या कहलाता है?

  1. बूटिंग
  2. स्पूलिंग
  3. एजिंग
  4. पेजिंग
उत्तर: एजिंग। यह स्टार्वेशन रोकता है।

प्र3. macOS में विंडोज़ के रीसायकल बिन के समान क्या है?

  1. डॉक
  2. स्पॉटलाइट
  3. फ़ाइंडर
  4. ट्रैश
उत्तर: ट्रैश। फ़ाइंडर macOS का फ़ाइल मैनेजर है।

प्र4. प्रक्रियाएँ समय 0 पर P1, P2, P3 क्रम में आती हैं; बर्स्ट समय P1 = 4, P2 = 6, P3 = 2 (ms) हैं। FCFS में औसत टर्नअराउंड समय कितना है?

  1. 8.67 ms
  2. 9.67 ms
  3. 4.67 ms
  4. 12 ms
उत्तर: 8.67 ms। टर्नअराउंड = प्रतीक्षा + बर्स्ट: 4, 10, 12। औसत = 26 ÷ 3 = 8.67 ms।

प्र5. जिस ऑपरेटिंग सिस्टम को कड़ी समय सीमा में प्रतिक्रिया देनी हो, जैसे विमान नियंत्रण या चिकित्सा मशीनें, वह क्या है?

  1. डेस्कटॉप OS
  2. रियल-टाइम ऑपरेटिंग सिस्टम (RTOS)
  3. बैच OS
  4. नेटवर्क OS
उत्तर: रियल-टाइम ऑपरेटिंग सिस्टम (RTOS)। समय सीमा चूकना ख़तरनाक हो सकता है।

प्र6. CLI की तुलना में GUI:

  1. बिना किसी विंडो के है
  2. कठिन है क्योंकि हर आदेश टाइप करना पड़ता है
  3. शुरुआती लोगों के लिए आसान है, क्योंकि इसमें चित्र और माउस होते हैं
  4. केवल सर्वर के लिए है
उत्तर: शुरुआती लोगों के लिए आसान है, क्योंकि इसमें चित्र और माउस होते हैं। CLI में आदेश याद रखने पड़ते हैं।

प्र7. कौन-सा DOS आदेश नई डायरेक्टरी (फ़ोल्डर) बनाता है?

  1. CLS
  2. MD (MKDIR)
  3. RD
  4. DEL
उत्तर: MD (MKDIR)। RD डायरेक्टरी हटाता है।

प्र8. विंडोज़ में पेन ड्राइव से हटाई गई फ़ाइलें प्रायः:

  1. स्टार्ट मेनू में जाती हैं
  2. रीसायकल बिन में जाती हैं
  3. रीसायकल बिन में नहीं जातीं, सीधे हट जाती हैं
  4. डेस्कटॉप पर चली जाती हैं
उत्तर: रीसायकल बिन में नहीं जातीं, सीधे हट जाती हैं। केवल आंतरिक हार्ड डिस्क से हटाई फ़ाइलें रीसायकल बिन में जाती हैं।

प्र9. प्रक्रियाएँ P1, P2, P3 सभी समय 0 पर आती हैं; बर्स्ट समय P1 = 24, P2 = 3, P3 = 3 (ms) हैं। नॉन-प्रीएम्प्टिव SJF (सबसे छोटा कार्य पहले) में औसत प्रतीक्षा समय कितना है?

  1. 13 ms
  2. 3 ms
  3. 17 ms
  4. 5 ms
उत्तर: 3 ms। सबसे छोटे बर्स्ट के क्रम में चलाएँ। प्रतीक्षा समय (P1, P2, P3): 6, 0, 3। औसत = 9 ÷ 3 = 3 ms।

प्र10. जो शेड्यूलिंग विधि चल रहे प्रोसेस के पूरा होने से पहले उससे CPU ले सकती है, वह क्या कहलाती है?

  1. नॉन-प्री-एम्प्टिव
  2. केवल कोऑपरेटिव
  3. बैच
  4. प्री-एम्प्टिव
उत्तर: प्री-एम्प्टिव। राउंड रॉबिन प्री-एम्प्टिव है।
