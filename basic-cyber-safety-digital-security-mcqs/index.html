Sample Basic Cyber Safety & Digital Security questions with answers

Q1. What is 'phishing'?

'फ़िशिंग' क्या है?

  1. A way to speed up the internet
  2. Fake messages or websites made to steal personal details
  3. A type of computer hardware
  4. A method of backing up files
Answer: Fake messages or websites made to steal personal details. Phishing uses fake emails, SMS or websites to trick people into sharing passwords, OTPs or bank details.
फ़िशिंग में नकली ईमेल, SMS या वेबसाइट से लोगों को धोखा देकर पासवर्ड, OTP या बैंक जानकारी ली जाती है।

Q2. Running a suspicious program in an isolated, safe area so it cannot harm the system is called:

संदिग्ध प्रोग्राम को अलग, सुरक्षित क्षेत्र में चलाना ताकि वह सिस्टम को नुकसान न पहुँचा सके:

  1. Sandboxing
  2. Spamming
  3. Caching
  4. Phishing
Answer: Sandboxing. Sandboxing runs a program in an isolated space so that it cannot harm the real system.
सैंडबॉक्सिंग में प्रोग्राम को एक अलग सुरक्षित जगह में चलाया जाता है ताकि वह असली सिस्टम को नुकसान न पहुँचा सके।

Q3. A torch app asking for permission to read your contacts and SMS is:

टॉर्च ऐप आपके संपर्क और SMS पढ़ने की अनुमति माँगे, तो यह:

  1. Normal and safe
  2. Suspicious — deny permissions it does not need
  3. Required by law
  4. Needed for the light to work
Answer: Suspicious — deny permissions it does not need. A torch app needs only the flashlight; asking for contacts and SMS is a warning sign, so deny such permissions.
टॉर्च ऐप को केवल फ़्लैशलाइट चाहिए; संपर्क और SMS माँगना ख़तरे का संकेत है, ऐसी अनुमति न दें।

Q4. A weakness in software that an attacker can use is called a:

सॉफ़्टवेयर की वह कमज़ोरी जिसका हमलावर उपयोग कर सके, क्या कहलाती है?

  1. Feature
  2. Vulnerability
  3. Shortcut
  4. Driver
Answer: Vulnerability. A program that uses it is an 'exploit'.
इसका उपयोग करने वाला प्रोग्राम 'एक्सप्लॉइट' है।

Q5. In authentication, a fingerprint is 'something you ARE'. A password is 'something you':

प्रमाणीकरण में फ़िंगरप्रिंट 'आप जो हैं' है। पासवर्ड 'आप जो ...' है:

  1. Have
  2. Buy
  3. Are
  4. Know
Answer: Know. An OTP on your phone is 'something you have'.
आपके फ़ोन पर आया OTP 'आप जो रखते हैं' है।

Q6. Regular good habits like updating software, using strong passwords and taking backups are called:

सॉफ़्टवेयर अपडेट करना, मज़बूत पासवर्ड और बैकअप जैसी नियमित अच्छी आदतें क्या कहलाती हैं?

  1. Cyber squatting
  2. Cyber crime
  3. Cyber stalking
  4. Cyber hygiene
Answer: Cyber hygiene. Cyber hygiene means regular safe habits, like daily personal hygiene for health.
साइबर हाइजीन का अर्थ है नियमित सुरक्षित आदतें, जैसे स्वास्थ्य के लिए रोज़ की साफ़-सफ़ाई।

Q7. Which is the best password practice?

पासवर्ड की सबसे अच्छी आदत कौन-सी है?

  1. Use your name and birth year
  2. Use the same password everywhere
  3. Write it on a sticky note on the monitor
  4. Use a long, different password for each account
Answer: Use a long, different password for each account. Long, unique passwords mean that a leak of one account does not expose the others; a password manager helps.
लंबे और अलग-अलग पासवर्ड से एक खाते के लीक होने पर बाकी सुरक्षित रहते हैं; पासवर्ड मैनेजर मदद करता है।

Q8. WhatsApp messages are protected so that only the sender and receiver can read them. This is called:

व्हाट्सऐप संदेश ऐसे सुरक्षित रहते हैं कि केवल भेजने वाला और पाने वाला पढ़ सकें। यह क्या कहलाता है?

  1. End-to-end encryption
  2. Spam filtering
  3. Cloud backup
  4. Compression
Answer: End-to-end encryption. With end-to-end encryption only the sender's and receiver's devices hold the keys; not even WhatsApp can read the messages.
एंड-टू-एंड एन्क्रिप्शन में कुंजी केवल भेजने और पाने वाले के उपकरण में होती है; व्हाट्सऐप भी संदेश नहीं पढ़ सकता।

Q9. A website address 'www.sbi-online-kyc-update.xyz' asking for net-banking login is most likely:

नेट-बैंकिंग लॉगिन माँगने वाला वेबसाइट पता 'www.sbi-online-kyc-update.xyz' सबसे अधिक संभवतः:

  1. A government portal
  2. A phishing site
  3. SBI's official site
  4. A safe mirror site
Answer: A phishing site. Bank sites use their official domain; check the URL carefully.
बैंक साइटें अपने आधिकारिक डोमेन का उपयोग करती हैं; URL ध्यान से जाँचें।

Q10. Which of these is an antivirus made by an Indian company?

इनमें से कौन भारतीय कंपनी का एंटीवायरस है?

  1. Kaspersky
  2. Norton
  3. Avast
  4. Quick Heal
Answer: Quick Heal. Quick Heal is from Pune. Norton is American, Kaspersky Russian, Avast Czech.
क्विक हील पुणे की है। नॉर्टन अमेरिकी, कैस्परस्की रूसी, अवास्ट चेक है।
