Sample Files, Folders & Extensions questions with answers

Q1. Which file extension is used for a PDF document?

PDF दस्तावेज़ का फ़ाइल एक्सटेंशन क्या है?

  1. .exe
  2. .jpg
  3. .doc
  4. .pdf
Answer: .pdf. PDF files end with .pdf.
PDF फ़ाइलें .pdf पर समाप्त होती हैं।

Q2. A file with the extension '.docx' is:

'.docx' एक्सटेंशन वाली फ़ाइल क्या है?

  1. A Microsoft Word document (2007 and later)
  2. A lossless compressed audio file
  3. A compressed archive made by 7-Zip
  4. A Java source program
Answer: A Microsoft Word document (2007 and later). Older Word files used .doc.
पुराने वर्ड दस्तावेज़ .doc होते थे।

Q3. A file with the extension '.tiff' is:

'.tiff' एक्सटेंशन वाली फ़ाइल क्या है?

  1. An older Microsoft Word document (Word 97–2003)
  2. An older Microsoft PowerPoint presentation
  3. A high-quality image format used in printing and scanning
  4. An Apple QuickTime video
Answer: A high-quality image format used in printing and scanning. TIFF = Tagged Image File Format.
TIFF = टैग्ड इमेज फ़ाइल फ़ॉर्मैट।

Q4. Software installers for Apple Mac computers are often distributed as which kind of file?

ऐपल मैक कंप्यूटरों के सॉफ़्टवेयर इंस्टॉलर प्रायः किस प्रकार की फ़ाइल के रूप में आते हैं?

  1. .bat
  2. .dmg
  3. .apk
  4. .msi
Answer: .dmg. DMG = Apple disk image.
DMG = ऐपल डिस्क इमेज।

Q5. A file with the extension '.xml' is:

'.xml' एक्सटेंशन वाली फ़ाइल क्या है?

  1. A temporary file
  2. A file that stores structured data using tags
  3. A Rich Text Format document
  4. An uncompressed audio file
Answer: A file that stores structured data using tags. XML = eXtensible Markup Language.
XML = एक्सटेंसिबल मार्कअप लैंग्वेज।

Q6. A ZIP file that needs a password before its files can be extracted is:

जिस ZIP फ़ाइल से फ़ाइलें निकालने से पहले पासवर्ड चाहिए, वह क्या है?

  1. A hidden folder
  2. An encrypted (password-protected) archive
  3. A shortcut
  4. A corrupted file
Answer: An encrypted (password-protected) archive. Without the password, the contents cannot be read.
पासवर्ड के बिना सामग्री पढ़ी नहीं जा सकती।

Q7. A file with the extension '.ppt' is:

'.ppt' एक्सटेंशन वाली फ़ाइल क्या है?

  1. An older Microsoft PowerPoint presentation
  2. A vector image that stays sharp at any size
  3. A web page
  4. A font file
Answer: An older Microsoft PowerPoint presentation. Newer files use .pptx.
नई फ़ाइलें .pptx होती हैं।

Q8. Which folder name refers to the parent folder (one level up) in a path?

पाथ में कौन-सा फ़ोल्डर नाम मूल (एक स्तर ऊपर) फ़ोल्डर को दर्शाता है?

  1. ..
  2. .
  3. *
  4. ~
Answer: ... A single dot means the current folder.
एक बिंदु का अर्थ वर्तमान फ़ोल्डर है।

Q9. A file with the extension '.class' is:

'.class' एक्सटेंशन वाली फ़ाइल क्या है?

  1. An older Microsoft Word document (Word 97–2003)
  2. Compiled Java bytecode
  3. A compressed audio file, often used by Apple and YouTube
  4. An image format that can also hold short animations
Answer: Compiled Java bytecode. The JVM runs .class files.
JVM .class फ़ाइलें चलाती है।

Q10. Windows file names are case-insensitive. This means:

विंडोज़ फ़ाइल नाम केस-इनसेंसिटिव होते हैं। इसका अर्थ है:

  1. Names cannot contain numbers
  2. Only capital letters are allowed
  3. Capital letters are not allowed
  4. 'Notes.txt' and 'notes.txt' are treated as the same name
Answer: 'Notes.txt' and 'notes.txt' are treated as the same name. Linux file names are case-sensitive.
लिनक्स फ़ाइल नाम केस-सेंसिटिव होते हैं।
