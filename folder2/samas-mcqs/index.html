Sample Samas questions with answers

Q1. Which of these is an example of Karmadharay (कर्मधारय) samas?

निम्नलिखित में से कौन-सा कर्मधारय समास का उदाहरण है?

  1. बेखटके
  2. पथभ्रष्ट
  3. दाल-रोटी
  4. कमलनयन
Answer: कमलनयन. कमलनयन: कमल के समान नयन — Karmadharay samas. बेखटके: Avyayibhav · पथभ्रष्ट: Tatpurush · दाल-रोटी: Dvandva.
कमलनयन: कमल के समान नयन — कर्मधारय समास। बेखटके: अव्ययीभाव · पथभ्रष्ट: तत्पुरुष · दाल-रोटी: द्वंद्व।

Q2. Which samas (compound) is 'प्रतिदिन'?

'प्रतिदिन' में कौन-सा समास है?

  1. बहुव्रीहि समास
  2. अव्ययीभाव समास
  3. तत्पुरुष समास
  4. कर्मधारय समास
Answer: अव्ययीभाव समास. Vigrah: हर दिन. It is Avyayibhav samas.
विग्रह: हर दिन। अतः अव्ययीभाव समास।

Q3. Which samas (compound) is 'दशानन'?

'दशानन' में कौन-सा समास है?

  1. द्वंद्व समास
  2. कर्मधारय समास
  3. बहुव्रीहि समास
  4. तत्पुरुष समास
Answer: बहुव्रीहि समास. Vigrah: दस हैं आनन जिसके — अर्थात् रावण. It is Bahuvrihi samas.
विग्रह: दस हैं आनन जिसके — अर्थात् रावण। अतः बहुव्रीहि समास।

Q4. Which samas (compound) is 'पथभ्रष्ट'?

'पथभ्रष्ट' में कौन-सा समास है?

  1. द्वंद्व समास
  2. अव्ययीभाव समास
  3. तत्पुरुष समास
  4. द्विगु समास
Answer: तत्पुरुष समास. Vigrah: पथ से भ्रष्ट. It is Tatpurush samas.
विग्रह: पथ से भ्रष्ट। अतः तत्पुरुष समास।

Q5. Which compound word has the vigrah 'तीन भुजाओं का समूह'?

'तीन भुजाओं का समूह' — यह किस समस्त पद का विग्रह है?

  1. त्रिभुज
  2. नवरत्न
  3. चौराहा
  4. पंचवटी
Answer: त्रिभुज. 'तीन भुजाओं का समूह' → त्रिभुज (Dvigu samas).
'तीन भुजाओं का समूह' → त्रिभुज (द्विगु समास)।

Q6. Which samas (compound) is 'राम-लक्ष्मण'?

'राम-लक्ष्मण' में कौन-सा समास है?

  1. द्विगु समास
  2. कर्मधारय समास
  3. अव्ययीभाव समास
  4. द्वंद्व समास
Answer: द्वंद्व समास. Vigrah: राम और लक्ष्मण. It is Dvandva samas.
विग्रह: राम और लक्ष्मण। अतः द्वंद्व समास।

Q7. Which samas (compound) is 'गंगाजल'?

'गंगाजल' में कौन-सा समास है?

  1. द्वंद्व समास
  2. द्विगु समास
  3. अव्ययीभाव समास
  4. तत्पुरुष समास
Answer: तत्पुरुष समास. Vigrah: गंगा का जल. It is Tatpurush samas.
विग्रह: गंगा का जल। अतः तत्पुरुष समास।

Q8. Which compound word has the vigrah 'जन्म से अंधा'?

'जन्म से अंधा' — यह किस समस्त पद का विग्रह है?

  1. हस्तलिखित
  2. जन्मांध
  3. स्वर्गप्राप्त
  4. राष्ट्रपति
Answer: जन्मांध. 'जन्म से अंधा' → जन्मांध (Tatpurush samas).
'जन्म से अंधा' → जन्मांध (तत्पुरुष समास)।

Q9. Which samas (compound) is 'आमरण'?

'आमरण' में कौन-सा समास है?

  1. अव्ययीभाव समास
  2. कर्मधारय समास
  3. द्वंद्व समास
  4. द्विगु समास
Answer: अव्ययीभाव समास. Vigrah: मरण तक. It is Avyayibhav samas.
विग्रह: मरण तक। अतः अव्ययीभाव समास।

Q10. Which compound word has the vigrah 'हाथ ही हाथ में'?

'हाथ ही हाथ में' — यह किस समस्त पद का विग्रह है?

  1. भरपेट
  2. यथासमय
  3. बेखटके
  4. हाथोंहाथ
Answer: हाथोंहाथ. 'हाथ ही हाथ में' → हाथोंहाथ (Avyayibhav samas).
'हाथ ही हाथ में' → हाथोंहाथ (अव्ययीभाव समास)।
