Sample Inequality questions with answers

Q1. If A > B and B > C, which of the following is definitely true?

यदि A > B और B > C, तो निम्न में से क्या निश्चित रूप से सत्य है?

  1. C > A
  2. A > C
  3. A = C
  4. B > A
Answer: A > C. A is greater than B, and B is greater than C, so A is greater than C.
A, B से बड़ा है और B, C से बड़ा है, अतः A, C से बड़ा है।

Q2. Statement: S > Q ≥ L ≥ R = G Which of the following is definitely true?

कथन: S > Q ≥ L ≥ R = G निम्न में से क्या निश्चित रूप से सत्य है?

  1. Q > R
  2. Q < R
  3. R > Q
  4. Q ≥ R
Answer: Q ≥ R. Between Q and R the signs are ≥ ≥. Only '≥' and '=' appear, so the result is '≥'.
Q और R के बीच चिह्न ≥ ≥ हैं। केवल '≥' और '=' हैं, अतः परिणाम '≥' है।

Q3. Statement: F ≥ G > W ≥ V = K Which of the following is definitely true?

कथन: F ≥ G > W ≥ V = K निम्न में से क्या निश्चित रूप से सत्य है?

  1. W < V
  2. V > W
  3. W > V
  4. W ≥ V
Answer: W ≥ V. Between W and V the signs are ≥. Only '≥' and '=' appear, so the result is '≥'.
W और V के बीच चिह्न ≥ हैं। केवल '≥' और '=' हैं, अतः परिणाम '≥' है।

Q4. Statement: X > S = P ≥ C ≥ G Which of the following is definitely true?

कथन: X > S = P ≥ C ≥ G निम्न में से क्या निश्चित रूप से सत्य है?

  1. X > S
  2. X = S
  3. S > X
  4. S ≥ X
Answer: X > S. Between X and S the signs are >. There is at least one '>', so the result is '>'.
X और S के बीच चिह्न > हैं। कम से कम एक '>' है, अतः परिणाम '>' है।

  1. U < R
  2. U > R
  3. R > U
  4. U ≥ R
Answer: U ≥ R. Between U and R the signs are ≥. Only '≥' and '=' appear, so the result is '≥'.
U और R के बीच चिह्न ≥ हैं। केवल '≥' और '=' हैं, अतः परिणाम '≥' है।

Q6. Statement: G > Q > D = B = R Which of the following is definitely true?

कथन: G > Q > D = B = R निम्न में से क्या निश्चित रूप से सत्य है?

  1. R ≥ Q
  2. Q = R
  3. R > Q
  4. Q > R
Answer: Q > R. Between Q and R the signs are > = =. There is at least one '>', so the result is '>'.
Q और R के बीच चिह्न > = = हैं। कम से कम एक '>' है, अतः परिणाम '>' है।

Q7. Statement: R ≥ B = C = K Which of the following is definitely true?

कथन: R ≥ B = C = K निम्न में से क्या निश्चित रूप से सत्य है?

  1. B = K
  2. B > K
  3. B < K
  4. K > B
Answer: B = K. Between B and K the signs are = =. All are '=', so they are equal.
B और K के बीच चिह्न = = हैं। सभी '=' हैं, अतः दोनों बराबर हैं।

  3. K < J

Answer: K ≥ J. Between K and J the signs are ≥. Only '≥' and '=' appear, so the result is '≥'.

Q9. Statement: E ≥ C ≥ Y < X < D Conclusions: I. C ≥ D II. E > D

कथन: E ≥ C ≥ Y < X < D निष्कर्ष: I. C ≥ D II. E > D

  1. Only I follows
  2. Neither I nor II follows
  3. Both I and II follow
  4. Only II follows
Answer: Neither I nor II follows. I is not definitely true; II is not definitely true. (A conclusion holds only if all signs between the two letters point the same way.)
I निश्चित नहीं है; II निश्चित नहीं है। (निष्कर्ष तभी सही है जब दोनों अक्षरों के बीच सभी चिह्न एक ही दिशा में हों।)
