सामान्य कंप्यूटर संक्षिप्त रूप – हिंदी में निःशुल्क अभ्यास प्रश्न

सामान्य कंप्यूटर संक्षिप्त रूप कंप्यूटर जागरूकता का महत्वपूर्ण टॉपिक है, जो SSC, रेलवे, बैंकिंग और अन्य सरकारी परीक्षाओं में पूछा जाता है। यहाँ 199 निःशुल्क अभ्यास प्रश्न हिंदी और अंग्रेज़ी में हैं, सही उत्तर और व्याख्या के साथ, और छोटे रिवीज़न नोट्स भी।

छोटे नोट्स पढ़ेंव्याख्या के साथ अभ्यास10 प्रश्नों की क्विज़समयबद्ध टॉपिक टेस्ट

वेबसाइट खुलने पर ऊपर हिंदी बटन दबाएँ, सभी प्रश्न और व्याख्या हिंदी में दिखेंगी।

सामान्य कंप्यूटर संक्षिप्त रूप – उत्तर सहित नमूना प्रश्न

प्र1. URL किसकी पहचान के लिए उपयोग होता है?

  1. वेब पेज का पता
  2. प्रिंटर का मॉडल
  3. कंप्यूटर की गति
  4. फ़ाइल का आकार
उत्तर: वेब पेज का पता। URL (Uniform Resource Locator) किसी वेब संसाधन का पता है।

प्र2. FLOPS का पूर्ण रूप क्या है?

  1. Floating Point Operations Per Second
  2. Fixed Logic Operations Per Second
  3. Floating Point Outputs Per Step
  4. Fast Logical Operations Per Second
उत्तर: Floating Point Operations Per Second। FLOPS = Floating Point Operations Per Second। सुपरकंप्यूटर की गति FLOPS में मापी जाती है।

प्र3. 'Magnetic Ink Character Recognition' (मैग्नेटिक इंक कैरेक्टर रिकग्निशन) का संक्षिप्त रूप कौन-सा है?

  1. MIRC
  2. MICR
  3. OMR
  4. OCR
उत्तर: MICR। MICR चेक के चुंबकीय अंक पढ़ता है।

प्र4. KB का पूरा नाम क्या है?

  1. Kilobyte
  2. Key Byte
  3. Kilobit
  4. Keyboard
उत्तर: Kilobyte। KB = Kilobyte। 1 KB = 1024 बाइट।

प्र5. CD का पूर्ण रूप क्या है?

  1. Computer Disc
  2. Compact Disc
  3. Copy Disc
  4. Central Disc
उत्तर: Compact Disc। CD = Compact Disc।

प्र6. HDD का पूरा नाम क्या है?

  1. Hard Disk Drive
  2. Hard Data Drive
  3. High Disk Drive
  4. High Density Disk
उत्तर: Hard Disk Drive। HDD = Hard Disk Drive।

प्र7. 'Dynamic Host Configuration Protocol' (डायनेमिक होस्ट कॉन्फ़िगरेशन प्रोटोकॉल) का संक्षिप्त रूप कौन-सा है?

  1. DHCP
  2. HTTP
  3. DCHP
  4. DNS
उत्तर: DHCP। DHCP अपने-आप IP पता देता है।

प्र8. ALU का पूरा नाम क्या है?

  1. Array Logic Unit
  2. Arithmetic Language Unit
  3. Automatic Logic Unit
  4. Arithmetic Logic Unit
उत्तर: Arithmetic Logic Unit। ALU = Arithmetic Logic Unit। यह गणना और तुलना करता है।

प्र9. CAD का पूरा नाम क्या है?

  1. Computer-Aided Drawing Device
  2. Computer-Aided Design
  3. Central Automatic Design
  4. Computer Application Development
उत्तर: Computer-Aided Design। CAD = Computer-Aided Design। इंजीनियर और वास्तुकार इसका उपयोग करते हैं।

प्र10. कंप्यूटर में NPCI का अर्थ है:

  1. National Payments Corporation of India
  2. New Payments Corporation of India
  3. National Phone Corporation of India
  4. National Payment Council of India
उत्तर: National Payments Corporation of India। NPCI = National Payments Corporation of India। यह UPI, RuPay और IMPS चलाता है।
