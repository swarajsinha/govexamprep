  2. QJ
  3. JR

उत्तर: JQ। पहला अक्षर 2 आगे, दूसरा अक्षर 2 पीछे जाता है।

प्र8. निम्नलिखित श्रृंखला में प्रश्नचिह्न (?) के स्थान पर क्या आएगा? 4, 8, 18, 40, 86, ?

  1. 171
  2. 180
  3. 199
  4. 189
उत्तर: 180। नियम: ×2, फिर बारी-बारी से 0, 2, 4, … जोड़ें। अगला पद = 180।

  2. 251
  3. 222
  4. 208
उत्तर: 222। नियम: हर पद = पिछला × 2 + 2। अगला पद = 222।
