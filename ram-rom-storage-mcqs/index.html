Sample RAM, ROM & Storage questions with answers

Q1. Which of the following is a volatile memory (data is lost when power goes off)?

निम्न में से कौन-सी अस्थायी (volatile) मेमोरी है (बिजली जाने पर डेटा मिट जाता है)?

  1. ROM
  2. RAM
  3. Hard disk
  4. Pen drive
Answer: RAM. RAM is volatile: its contents are lost when power is switched off.
RAM अस्थायी होती है: बिजली बंद होने पर इसका डेटा मिट जाता है।

Q2. A photo is 2 MB. How many photos can be stored in a 32 GB memory card (binary units)?

एक फ़ोटो 2 MB की है। 32 GB के मेमोरी कार्ड (बाइनरी इकाइयों) में कितनी फ़ोटो रखी जा सकती हैं?

  1. 32,000
  2. 16,000
  3. 16,384
  4. 64
Answer: 16,384. 32 × 1024 = 32,768 MB; ÷ 2 = 16,384.
32 × 1024 = 32,768 MB; ÷ 2 = 16,384।

Q3. EPROM chips are erased by exposing them to:

EPROM चिप को मिटाने के लिए उन्हें किसके संपर्क में लाया जाता है?

  1. Sound waves
  2. Magnets only
  3. Ultraviolet (UV) light
  4. Water
Answer: Ultraviolet (UV) light. EPROM chips have a small glass window for UV light.
EPROM चिप में UV प्रकाश के लिए छोटी काँच की खिड़की होती है।

Q4. The memory in a calculator or washing machine that holds its fixed working program is usually:

कैलकुलेटर या वॉशिंग मशीन में उसका निश्चित कार्य-प्रोग्राम रखने वाली मेमोरी प्रायः कौन-सी होती है?

  1. Cloud storage
  2. Magnetic tape
  3. ROM / flash
  4. DVD
Answer: ROM / flash. Embedded devices keep their firmware in non-volatile chips.
एम्बेडेड उपकरण अपना फ़र्मवेयर नॉन-वोलेटाइल चिप में रखते हैं।

Q5. DVD stands for:

DVD का पूर्ण रूप क्या है?

  1. Digital Versatile Disc
  2. Direct Video Drive
  3. Digital Volume Data
  4. Disk Video Display
Answer: Digital Versatile Disc. It was first called Digital Video Disc.
पहले इसे Digital Video Disc कहा जाता था।

Q6. When RAM is full, the operating system uses a part of the hard disk as if it were RAM. This is called:

RAM भर जाने पर ऑपरेटिंग सिस्टम हार्ड डिस्क के एक भाग को RAM की तरह उपयोग करता है। इसे क्या कहते हैं?

  1. Virtual memory
  2. ROM
  3. Flash memory
  4. Cache memory
Answer: Virtual memory. It lets bigger programs run, but is slower than real RAM.
इससे बड़े प्रोग्राम चल पाते हैं, पर यह असली RAM से धीमी है।

Q7. Optical discs like CDs and DVDs are read using a:

CD और DVD जैसी ऑप्टिकल डिस्क किससे पढ़ी जाती हैं?

  1. Laser beam
  2. Pen
  3. Microphone
  4. Magnetic head
Answer: Laser beam. The laser detects tiny pits and lands on the disc.
लेज़र डिस्क पर छोटे गड्ढों और समतल भागों को पहचानता है।

Q8. A phone has 256 GB of storage and 175 GB is already used. How much storage is free?

एक फ़ोन में 256 GB स्टोरेज है और 175 GB पहले से भरी है। कितनी स्टोरेज खाली है?

  1. 81 GB
  2. 91 GB
  3. 71 GB
  4. 175 GB
Answer: 81 GB. 256 − 175 = 81 GB.
256 − 175 = 81 GB।

Q9. How many bits are there in 12 nibbles?

12 निबल में कितने बिट होते हैं?

  1. 24 bits
  2. 192 bits
  3. 48 bits
  4. 96 bits
Answer: 48 bits. 1 nibble = 4 bits, so 12 nibbles = 12 × 4 = 48 bits.
1 निबल = 4 बिट, अतः 12 निबल = 12 × 4 = 48 बिट।

Q10. How many bits are there in 12 bytes?

12 बाइट में कितने बिट होते हैं?

  1. 96 bits
  2. 120 bits
  3. 48 bits
  4. 192 bits
Answer: 96 bits. 1 byte = 8 bits, so 12 bytes = 12 × 8 = 96 bits.
1 बाइट = 8 बिट, अतः 12 बाइट = 12 × 8 = 96 बिट।
