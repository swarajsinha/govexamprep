Sample Keyboard & Common Shortcuts questions with answers

Q1. Which keyboard shortcut is used to copy selected text?

चयनित टेक्स्ट को कॉपी करने के लिए कौन-सा शॉर्टकट उपयोग होता है?

  1. Ctrl + V
  2. Ctrl + X
  3. Ctrl + C
  4. Ctrl + Z
Answer: Ctrl + C. Ctrl + C copies, Ctrl + V pastes, Ctrl + X cuts and Ctrl + Z undoes.
Ctrl + C कॉपी, Ctrl + V पेस्ट, Ctrl + X कट और Ctrl + Z अनडू करता है।

Q2. In MS Office programs, pressing the Alt key alone:

MS ऑफ़िस प्रोग्रामों में केवल Alt कुंजी दबाने से:

  1. Closes the program
  2. Saves the file
  3. Shows key tips (letters) for the ribbon tabs
  4. Opens Help
Answer: Shows key tips (letters) for the ribbon tabs. You can then press a letter to open a tab without the mouse.
फिर बिना माउस के अक्षर दबाकर टैब खोल सकते हैं।

Q3. In Windows, the shortcut Windows key + I is used to:

विंडोज़ में शॉर्टकट Windows key + I का उपयोग किसलिए होता है?

  1. Show information about a file
  2. Open Settings
  3. Open Internet Explorer
  4. Insert an image
Answer: Open Settings. Windows key + I = Open Settings.
Windows key + I = सेटिंग्स खोलना।

Q4. In Windows, the shortcut Windows key + Left arrow is used to:

विंडोज़ में शॉर्टकट Windows key + Left arrow का उपयोग किसलिए होता है?

  1. Snap the window to the left half of the screen
  2. Move the cursor left
  3. Go back one page
  4. Minimise the window
Answer: Snap the window to the left half of the screen. Windows key + Left arrow = Snap the window to the left half of the screen.
Windows key + Left arrow = विंडो को स्क्रीन के बाएँ आधे भाग में लगाना (स्नैप)।

Q5. In a web browser such as Chrome, the shortcut Ctrl + F5 is used to:

क्रोम जैसे वेब ब्राउज़र में शॉर्टकट Ctrl + F5 का उपयोग किसलिए होता है?

  1. Close the browser
  2. Print the page
  3. Reload the page fully, ignoring saved (cached) copies
  4. Open full screen
Answer: Reload the page fully, ignoring saved (cached) copies. Ctrl + F5 = Reload the page fully, ignoring saved (cached) copies. Plain F5 does a normal reload.
Ctrl + F5 = सेव (कैश) की गई प्रतियों को छोड़कर पेज पूरी तरह दोबारा लोड करना। केवल F5 सामान्य रीलोड करता है।

Q6. In Windows, the shortcut Windows key + . (full stop) is used to:

विंडोज़ में शॉर्टकट Windows key + . (full stop) का उपयोग किसलिए होता है?

  1. Shut down the computer
  2. Lock the screen
  3. Open the emoji panel
  4. Open the dot menu
Answer: Open the emoji panel. Windows key + . (full stop) = Open the emoji panel.
Windows key + . (full stop) = इमोजी पैनल खोलना।

Q7. In MS Word, the shortcut Ctrl + U is used to:

MS वर्ड में शॉर्टकट Ctrl + U का उपयोग किसलिए होता है?

  1. Update fields
  2. Undo
  3. Underline text
  4. Make text uppercase
Answer: Underline text. Ctrl + U = Underline text.
Ctrl + U = पाठ को रेखांकित करना।

Q8. In MS Excel, the shortcut Alt + Enter is used to:

MS एक्सेल में शॉर्टकट Alt + Enter का उपयोग किसलिए होता है?

  1. Move to the next cell
  2. Open cell properties
  3. Start a new line inside the same cell
  4. Insert a new row
Answer: Start a new line inside the same cell. Alt + Enter = Start a new line inside the same cell. Plain Enter moves to the cell below.
Alt + Enter = उसी सेल के अंदर नई पंक्ति शुरू करना। केवल Enter नीचे वाले सेल पर ले जाता है।

Q9. Which of these is NOT a toggle key?

इनमें से कौन टॉगल कुंजी नहीं है?

  1. Scroll Lock
  2. Caps Lock
  3. Ctrl
  4. Num Lock
Answer: Ctrl. Ctrl is a modifier key, used with other keys.
Ctrl एक मॉडिफ़ायर कुंजी है, जो दूसरी कुंजियों के साथ उपयोग होती है।

Q10. In PowerPoint, the shortcut B (during a slide show) is used to:

पावरपॉइंट में शॉर्टकट B (during a slide show) का उपयोग किसलिए होता है?

  1. Go back one slide
  2. Make text bold
  3. Show a black screen (press again to return)
  4. Show a white screen
Answer: Show a black screen (press again to return). B (during a slide show) = Show a black screen (press again to return). W shows a white screen.
B (during a slide show) = काली स्क्रीन दिखाना (वापस आने के लिए दोबारा दबाएँ)। W सफ़ेद स्क्रीन दिखाता है।
