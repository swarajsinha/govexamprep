Sample Hardware & Software questions with answers

Q1. Which of the following is hardware?

निम्न में से कौन-सा हार्डवेयर है?

  1. Keyboard
  2. MS Word
  3. Antivirus
  4. Windows
Answer: Keyboard. A keyboard is a physical part; the others are software.
कीबोर्ड भौतिक भाग है; बाकी सॉफ़्टवेयर हैं।

Q2. The Python programming language was created by:

पायथन प्रोग्रामिंग भाषा किसने बनाई?

  1. Bill Gates
  2. Dennis Ritchie
  3. Charles Babbage
  4. Guido van Rossum
Answer: Guido van Rossum. Python was first released in 1991.
पायथन पहली बार 1991 में जारी हुई।

Q3. Changing an old version of software to a newer, improved version is called:

सॉफ़्टवेयर के पुराने संस्करण को नए, बेहतर संस्करण में बदलना क्या कहलाता है?

  1. Formatting
  2. Upgrading
  3. Uninstalling
  4. Downgrading
Answer: Upgrading. Updates and upgrades add features and fixes.
अपडेट और अपग्रेड नई सुविधाएँ और सुधार जोड़ते हैं।

Q4. LISP, one of the oldest languages still in use, is closely linked with:

आज भी प्रयुक्त सबसे पुरानी भाषाओं में से एक LISP किससे जुड़ी है?

  1. Printing
  2. Bank cheques
  3. Artificial intelligence research
  4. Spreadsheets
Answer: Artificial intelligence research. It was created by John McCarthy in 1958.
इसे जॉन मैकार्थी ने 1958 में बनाया।

Q5. The group of chips on the motherboard that controls the flow of data between the processor, memory and other parts is called the:

मदरबोर्ड पर चिप्स का वह समूह जो प्रोसेसर, मेमोरी और अन्य भागों के बीच डेटा का प्रवाह नियंत्रित करता है, क्या कहलाता है?

  1. Cache
  2. Toolbar
  3. Firmware
  4. Chipset
Answer: Chipset. The chipset works like a traffic controller on the motherboard.
चिपसेट मदरबोर्ड पर ट्रैफ़िक नियंत्रक जैसा काम करता है।

Q6. JavaScript, used to make web pages interactive, was created by:

वेब पेजों को इंटरैक्टिव बनाने वाली जावास्क्रिप्ट किसने बनाई?

  1. Brendan Eich
  2. James Gosling
  3. Tim Berners-Lee
  4. Bjarne Stroustrup
Answer: Brendan Eich. Despite the name, JavaScript is different from Java.
नाम मिलता-जुलता होने पर भी जावास्क्रिप्ट जावा से अलग है।

Q7. Mobile applications on Android phones are commonly downloaded from:

एंड्रॉइड फ़ोन के मोबाइल एप्लिकेशन प्रायः कहाँ से डाउनलोड किए जाते हैं?

  1. Control Panel
  2. Recycle Bin
  3. Google Play Store
  4. BIOS
Answer: Google Play Store. Apple iPhones use the App Store.
ऐपल आईफ़ोन में ऐप स्टोर उपयोग होता है।

Q8. Which of the following is a utility program?

निम्न में से कौन-सा यूटिलिटी प्रोग्राम है?

  1. Adobe Photoshop
  2. Tally
  3. Disk Defragmenter
  4. MS PowerPoint
Answer: Disk Defragmenter. Defragmenting rearranges file pieces on a hard disk.
डीफ़्रैगमेंटिंग हार्ड डिस्क पर फ़ाइल के टुकड़ों को फिर से क्रम में रखती है।

Q9. Software specially written for the needs of one particular organisation is called:

किसी एक विशेष संस्था की ज़रूरतों के लिए अलग से बनाया गया सॉफ़्टवेयर क्या कहलाता है?

  1. Firmware
  2. Packaged software
  3. Freeware
  4. Custom (tailor-made) software
Answer: Custom (tailor-made) software. For example, a railway's own reservation system.
जैसे रेलवे की अपनी आरक्षण प्रणाली।

Q10. A program that joins object code files and library files into one executable program is called a:

ऑब्जेक्ट कोड फ़ाइलों और लाइब्रेरी फ़ाइलों को जोड़कर एक एक्ज़ीक्यूटेबल प्रोग्राम बनाने वाला प्रोग्राम क्या कहलाता है?

  1. Debugger
  2. Loader
  3. Linker
  4. Assembler
Answer: Linker. The loader then places it in memory to run.
फिर लोडर उसे चलाने के लिए मेमोरी में रखता है।
