Sample Analogy questions with answers

Q1. Doctor : Hospital :: Teacher : ?

डॉक्टर : अस्पताल :: शिक्षक : ?

  1. Book
  2. School
  3. Student
  4. Class test
Answer: School. A doctor works in a hospital; similarly, a teacher works in a school.
डॉक्टर अस्पताल में काम करता है; उसी प्रकार शिक्षक विद्यालय में काम करता है।

Q2. IK : LN :: MO : ?

IK : LN :: MO : ?

  1. PR
  2. OQ
  3. PS
  4. QS
Answer: PR. Each letter moves 3 places forward: IK → LN, so MO → PR.
हर अक्षर 3 स्थान आगे जाता है: IK → LN, अतः MO → PR

Q3. 6 : 17 :: 2 : ?

6 : 17 :: 2 : ?

  1. 8
  2. 3
  3. 6
  4. 5
Answer: 5. Rule: x → 3x − 1. 6 → 17, so 2 → 5.
नियम: x → 3x − 1। 6 → 17, अतः 2 → 5

Q4. DF : IK :: HJ : ?

DF : IK :: HJ : ?

  1. MP
  2. LN
  3. MO
  4. NP
Answer: MO. Each letter moves 5 places forward: DF → IK, so HJ → MO.
हर अक्षर 5 स्थान आगे जाता है: DF → IK, अतः HJ → MO

Q5. 3 : 8 :: 11 : ?

3 : 8 :: 11 : ?

  1. 35
  2. 32
  3. 33
  4. 30
Answer: 32. Rule: x → 3x − 1. 3 → 8, so 11 → 32.
नियम: x → 3x − 1। 3 → 8, अतः 11 → 32

Q6. Tailor : Needle :: Barber : ?

दर्ज़ी : सुई :: नाई : ?

  1. Scissors
  2. Pen
  3. Brush
  4. Stethoscope
Answer: Scissors. The second word is the tool of the first. The tool of Barber is Scissors.
दूसरा शब्द पहले का औज़ार है। नाई का औज़ार कैंची है।

Q7. KM : PR :: EG : ?

KM : PR :: EG : ?

  1. KM
  2. JL
  3. IK
  4. JM
Answer: JL. Each letter moves 5 places forward: KM → PR, so EG → JL.
हर अक्षर 5 स्थान आगे जाता है: KM → PR, अतः EG → JL

Q8. KL : LM :: JK : ?

KL : LM :: JK : ?

  1. KM
  2. LM
  3. JK
  4. KL
Answer: KL. Each letter moves 1 place forward: KL → LM, so JK → KL.
हर अक्षर 1 स्थान आगे जाता है: KL → LM, अतः JK → KL

Q9. Choose the number that fits: 14 : 197 :: 7 : ?

उपयुक्त संख्या चुनें: 14 : 197 :: 7 : ?

  1. 50
  2. 57
  3. 51
  4. 48
Answer: 50. Rule: n → n² + 1. 14 → 197, so 7 → 50.
नियम: n → n² + 1। 14 → 197, अतः 7 → 50।

Q10. Choose the number that fits: 6 : 216 :: 8 : ?

उपयुक्त संख्या चुनें: 6 : 216 :: 8 : ?

  1. 513
  2. 510
  3. 512
  4. 520
Answer: 512. Rule: n → n³. 6 → 216, so 8 → 512.
नियम: n → n³। 6 → 216, अतः 8 → 512।
