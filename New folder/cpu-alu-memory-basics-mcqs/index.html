Sample CPU, ALU & Memory Basics questions with answers

Q1. Which part is called the 'brain' of the computer?

कंप्यूटर का 'मस्तिष्क' किस भाग को कहा जाता है?

  1. Monitor
  2. CPU
  3. Keyboard
  4. Hard disk
Answer: CPU. The CPU (Central Processing Unit) processes all instructions, so it is called the brain of the computer.
CPU (सेंट्रल प्रोसेसिंग यूनिट) सभी निर्देशों को प्रोसेस करता है, इसलिए इसे कंप्यूटर का मस्तिष्क कहा जाता है।

Q2. A 'hexa-core' processor has how many cores?

'हेक्सा-कोर' प्रोसेसर में कितने कोर होते हैं?

  1. 12
  2. 6
  3. 4
  4. 8
Answer: 6. Hexa = six.
हेक्सा = छह।

Q3. A stack, used by the CPU to store return addresses, works on which principle?

CPU द्वारा लौटने के पते रखने के लिए प्रयुक्त स्टैक किस सिद्धांत पर चलता है?

  1. Largest first
  2. First In, First Out (FIFO)
  3. Last In, First Out (LIFO)
  4. Random order
Answer: Last In, First Out (LIFO). Like a pile of plates: the last one placed is taken first.
प्लेटों के ढेर की तरह: अंत में रखी प्लेट पहले उठती है।

Q4. The world's first commercially available single-chip microprocessor (1971) was the:

दुनिया का पहला व्यावसायिक रूप से उपलब्ध सिंगल-चिप माइक्रोप्रोसेसर (1971) कौन-सा था?

  1. Intel 8086
  2. Intel 4004
  3. Pentium
  4. Core i7
Answer: Intel 4004. The 4004 was a 4-bit processor.
4004 एक 4-बिट प्रोसेसर था।

Q5. A processor has a 20-bit address bus. How many different memory locations can it address?

किसी प्रोसेसर की एड्रेस बस 20-बिट की है। वह कितने अलग मेमोरी स्थानों को संबोधित कर सकता है?

  1. 4,294,967,296 (4 G)
  2. 1,048,576 (1 M)
  3. 16,777,216 (16 M)
  4. 1,024 (1 K)
Answer: 1,048,576 (1 M). Number of locations = 2^20 = 1,048,576 (1 M).
स्थानों की संख्या = 2^20 = 1,048,576 (1 M)।

Q6. What happens to the data in the CPU's registers when the power is switched off?

बिजली बंद होने पर CPU के रजिस्टरों के डेटा का क्या होता है?

  1. It is lost, because registers are volatile
  2. It moves to the printer
  3. It doubles
  4. It is saved permanently
Answer: It is lost, because registers are volatile. Registers, cache and RAM all need power to hold data.
रजिस्टर, कैश और RAM सभी को डेटा रखने के लिए बिजली चाहिए।

Q7. A single chip that contains a processor, memory and input/output controls, used in washing machines and toys, is a:

एक ही चिप जिसमें प्रोसेसर, मेमोरी और इनपुट/आउटपुट नियंत्रण हों, जो वॉशिंग मशीन और खिलौनों में लगती है, क्या कहलाती है?

  1. Mainframe
  2. Server
  3. Microcontroller
  4. Supercomputer
Answer: Microcontroller. Microcontrollers run embedded systems.
माइक्रोकंट्रोलर एम्बेडेड सिस्टम चलाते हैं।

Q8. 4.5 GHz is equal to how many megahertz (MHz)?

4.5 GHz कितने मेगाहर्ट्ज़ (MHz) के बराबर है?

  1. 4,500 MHz
  2. 9,000 MHz
  3. 45,000 MHz
  4. 450 MHz
Answer: 4,500 MHz. 1 GHz = 1000 MHz, so 4.5 GHz = 4,500 MHz.
1 GHz = 1000 MHz, अतः 4.5 GHz = 4,500 MHz।

Q9. Exynos processors used in some phones are made by:

कुछ फ़ोनों में प्रयुक्त एक्सीनॉस प्रोसेसर कौन बनाता है?

  1. AMD
  2. Nokia
  3. Samsung
  4. Intel
Answer: Samsung. Samsung designs Exynos chips.
सैमसंग एक्सीनॉस चिप डिज़ाइन करता है।

Q10. Among the CPU cache levels, which one is the smallest and fastest?

CPU के कैश स्तरों में सबसे छोटा और सबसे तेज़ कौन-सा है?

  1. L2 cache
  2. Hard disk cache
  3. L1 cache
  4. L3 cache
Answer: L1 cache. L1 is closest to each core; L3 is larger and shared.
L1 हर कोर के सबसे पास है; L3 बड़ा और साझा होता है।
