Sample Computer Basics & Terminology questions with answers

Q1. Who is known as the 'Father of the Computer'?

'कंप्यूटर का जनक' किसे कहा जाता है?

  1. Tim Berners-Lee
  2. Alan Turing
  3. Charles Babbage
  4. Bill Gates
Answer: Charles Babbage. Charles Babbage designed the Analytical Engine, an early mechanical computer.
चार्ल्स बैबेज ने एनालिटिकल इंजन बनाया, जो एक आरंभिक यांत्रिक कंप्यूटर था।

Q2. What is the decimal value of the hexadecimal number 64?

हेक्साडेसिमल संख्या 64 का दशमलव मान क्या है?

  1. 100
  2. 99
  3. 102
  4. 92
Answer: 100. 64 = 6 × 16 + 4 = 100.
64 = 6 × 16 + 4 = 100।

Q3. Raw, unorganised facts and figures given to a computer are called:

कंप्यूटर को दिए गए कच्चे, असंगठित तथ्य और आँकड़े क्या कहलाते हैं?

  1. Information
  2. Output
  3. Software
  4. Data
Answer: Data. Data becomes information after processing.
प्रोसेस होने के बाद डेटा सूचना बनता है।

Q4. In the hexadecimal system, the letter 'A' represents:

हेक्साडेसिमल पद्धति में 'A' किसे दर्शाता है?

  1. 11
  2. 1
  3. 10
  4. 16
Answer: 10. A = 10.
A = 10।

Q5. The 'stored program concept', in which both data and instructions are kept in memory, was proposed by:

'स्टोर्ड प्रोग्राम' अवधारणा, जिसमें डेटा और निर्देश दोनों मेमोरी में रहते हैं, किसने दी?

  1. Charles Babbage
  2. John von Neumann
  3. Tim Berners-Lee
  4. Alan Turing
Answer: John von Neumann. Most modern computers follow the von Neumann architecture.
अधिकांश आधुनिक कंप्यूटर वॉन न्यूमैन संरचना पर चलते हैं।

Q6. A computer that works on continuously changing data, like a speedometer, is a/an:

लगातार बदलते डेटा पर काम करने वाला कंप्यूटर, जैसे स्पीडोमीटर, क्या कहलाता है?

  1. Analog computer
  2. Hybrid computer
  3. Digital computer
  4. Micro computer
Answer: Analog computer. Analog computers measure continuous physical quantities.
एनालॉग कंप्यूटर लगातार बदलने वाली भौतिक राशियाँ मापते हैं।

Q7. An AND gate gives output 1 only when:

AND गेट आउटपुट 1 कब देता है?

  1. All inputs are 1
  2. All inputs are 0
  3. Inputs are different
  4. Any one input is 1
Answer: All inputs are 1. AND = all must be true.
AND = सभी सत्य होने चाहिए।

Q8. Which is considered the earliest known calculating device?

सबसे पुराना ज्ञात गणना उपकरण किसे माना जाता है?

  1. Slide rule
  2. Calculator
  3. Abacus
  4. Pascaline
Answer: Abacus. The abacus used beads on rods for counting.
अबेकस में गिनती के लिए छड़ों पर मनके होते थे।

Q9. What is the decimal value of the binary number 101100?

बाइनरी संख्या 101100 का दशमलव मान क्या है?

  1. 46
  2. 43
  3. 44
  4. 45
Answer: 44. Place values (right to left) are 1, 2, 4, 8, …; add those where the digit is 1. 101100₂ = 44.
स्थानीय मान (दाएँ से बाएँ) 1, 2, 4, 8, … हैं; जहाँ अंक 1 है वे जोड़ें। 101100₂ = 44।

Q10. The hexadecimal equivalent of the decimal number 108 is:

दशमलव संख्या 108 का हेक्साडेसिमल रूप है:

  1. 6D
  2. 6B
  3. 7C
  4. 6C
Answer: 6C. 108 ÷ 16 = 6 remainder 12. Digits 10–15 are written A–F, so 108 = 6C₁₆.
108 ÷ 16 = 6, शेष 12। 10–15 को A–F लिखते हैं, अतः 108 = 6C₁₆।
