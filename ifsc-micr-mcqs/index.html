Sample IFSC & MICR questions with answers

Q1. What is the full form of IFSC?

IFSC का पूर्ण रूप क्या है?

  1. Indian Financial System Code
  2. International Fund Security Code
  3. Indian Fund Service Code
  4. Inter Financial Safety Code
Answer: Indian Financial System Code. IFSC = Indian Financial System Code, an 11-character code that identifies a bank branch.
IFSC = Indian Financial System Code, यह 11 अक्षरों का कोड है जो बैंक शाखा की पहचान करता है।

Q2. The IFSC SBIN0001234 belongs to which bank?

IFSC SBIN0001234 किस बैंक का है?

  1. Indian Bank
  2. Union Bank of India
  3. Bank of Baroda
  4. State Bank of India
Answer: State Bank of India. The first four letters 'SBIN' identify State Bank of India.
पहले चार अक्षर 'SBIN' भारतीय स्टेट बैंक को दर्शाते हैं।

Q3. A SWIFT code of 8 characters (with no branch part) usually refers to the bank's:

8 अक्षरों का SWIFT कोड (बिना शाखा भाग के) प्रायः बैंक के किस कार्यालय को दर्शाता है?

  1. Head office / primary office
  2. ATM
  3. Customer's account
  4. Smallest village branch
Answer: Head office / primary office. An 8-character SWIFT code usually refers to the head (primary) office; an 11-character code adds a branch part.
8 अक्षरों का SWIFT कोड आम तौर पर मुख्य (प्राथमिक) कार्यालय का होता है; 11 अक्षरों में शाखा का भाग जुड़ता है।

Q4. A MICR code begins with 380. The cheque is most likely from which city?

एक MICR कोड 380 से शुरू होता है। चेक सबसे संभवतः किस शहर का है?

  1. Patna
  2. Ahmedabad
  3. Pune
  4. Kolkata
Answer: Ahmedabad. The first three digits of MICR match the city's PIN code (380 = Ahmedabad).
MICR के पहले तीन अंक शहर के पिन कोड से मेल खाते हैं (380 = अहमदाबाद)।

Q5. A MICR code begins with 800. The cheque is most likely from which city?

एक MICR कोड 800 से शुरू होता है। चेक सबसे संभवतः किस शहर का है?

  1. Bengaluru
  2. Delhi
  3. Mumbai
  4. Patna
Answer: Patna. The first three digits of MICR match the city's PIN code (800 = Patna).
MICR के पहले तीन अंक शहर के पिन कोड से मेल खाते हैं (800 = पटना)।

Q6. Which of these is in the correct IFSC format?

इनमें से कौन सही IFSC प्रारूप में है?

  1. ICI00012345
  2. ICIC1001234
  3. ICIC0001234
  4. ICIC000123
Answer: ICIC0001234. 4 letters (bank) + 0 + 6 characters (branch) = 11 characters.
4 अक्षर (बैंक) + 0 + 6 अक्षर (शाखा) = 11 अक्षर।

Q7. An IFSC has 11 characters. How many of them identify the branch?

IFSC में 11 अक्षर होते हैं। उनमें से कितने शाखा की पहचान करते हैं?

  1. 6
  2. 5
  3. 4
  4. 11
Answer: 6. 4 (bank) + 1 (zero) + 6 (branch).
4 (बैंक) + 1 (शून्य) + 6 (शाखा)।

Q8. In a CTS-2010 cheque, the word 'VOID' appears when the cheque is:

CTS-2010 चेक में 'VOID' शब्द कब दिखाई देता है?

  1. Signed
  2. Deposited
  3. Photocopied
  4. Folded
Answer: Photocopied. This is a security feature called a pantograph.
यह पैंटोग्राफ़ नामक सुरक्षा विशेषता है।

Q9. The letter 'F' in IFSC stands for:

IFSC में 'F' का अर्थ है:

  1. Federal
  2. Financial
  3. Fixed
  4. Fund
Answer: Financial. IFSC = Indian Financial System Code, so 'F' is Financial.
IFSC = इंडियन फ़ाइनेंशियल सिस्टम कोड, इसलिए 'F' = फ़ाइनेंशियल।

Q10. Each bank branch that takes part in NEFT/RTGS has:

NEFT/RTGS में भाग लेने वाली हर बैंक शाखा के पास क्या होता है?

  1. The same IFSC as all other branches
  2. Only a PIN code
  3. Its own unique IFSC
  4. No code
Answer: Its own unique IFSC. Each NEFT/RTGS branch has its own unique IFSC.
हर NEFT/RTGS शाखा का अपना अलग IFSC होता है।
