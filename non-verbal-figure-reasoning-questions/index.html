Sample Non-verbal / Figure Reasoning questions with answers

Q1. Which figure comes next in the series?

Answer: Option A. The arrow turns 45° clockwise each time.
तीर हर बार 45° दक्षिणावर्त घूमता है।

Q2. Which figure comes next in the series?

Answer: Option B. The dot moves one corner anticlockwise each time.
बिंदु हर बार एक कोना वामावर्त खिसकता है।

Q3. Which figure comes next in the series?

Answer: Option B. The arrow turns 90° anticlockwise each time.
तीर हर बार 90° वामावर्त घूमता है।

Q4. Which figure comes next in the series?

Answer: Option A. The arrow turns 135° clockwise each time.
तीर हर बार 135° दक्षिणावर्त घूमता है।

Q5. Which figure comes next in the series?

Answer: Option C. The arrow turns 90° anticlockwise each time.
तीर हर बार 90° वामावर्त घूमता है।

Q6. Which figure comes next in the series?

Answer: Option B. The shaded half turns 135° clockwise each time.
छायांकित आधा भाग हर बार 135° दक्षिणावर्त घूमता है।

Q7. Which figure comes next in the series?

Answer: Option B. The shaded half turns 90° anticlockwise each time.
छायांकित आधा भाग हर बार 90° वामावर्त घूमता है।

Q8. Which figure comes next in the series?

Answer: Option B. The shaded half turns 135° clockwise each time.
छायांकित आधा भाग हर बार 135° दक्षिणावर्त घूमता है।

Q9. Which figure comes next in the series?

Answer: Option B. The hand moves 3 hour-marks anticlockwise each time.
सुई हर बार 3 घंटे का निशान वामावर्त आगे बढ़ती है।

Q10. Which figure comes next in the series?
