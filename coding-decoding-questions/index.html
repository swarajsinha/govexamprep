Sample Coding-Decoding questions with answers

Q1. If CAT is written as DBU, how is DOG written in that code?

यदि CAT को DBU लिखा जाता है, तो उसी कूट में DOG को कैसे लिखा जाएगा?

  1. EPH
  2. EPG
  3. FPH
  4. DPH
Answer: EPH. Each letter moves one step forward: C→D, A→B, T→U. So D→E, O→P, G→H = EPH.
हर अक्षर एक स्थान आगे बढ़ता है: C→D, A→B, T→U। अतः D→E, O→P, G→H = EPH

Q2. If RAIN is written as OJBS, how is TIGER written?

यदि RAIN को OJBS लिखा जाता है, तो TIGER को कैसे लिखा जाएगा?

  1. UJHFS
  2. TGIKV
  3. REGIT
  4. SFHJU
Answer: SFHJU. Write the word in reverse order, then move each letter one place forward.
शब्द को उल्टे क्रम में लिखें, फिर हर अक्षर को एक स्थान आगे करें।

Q3. If RING is written as SJOH, how is BOOK written in that code?

यदि RING को SJOH लिखा जाता है, तो उसी कूट में BOOK को कैसे लिखा जाएगा?

  1. DQQM
  2. ANNJ
  3. LPPC
  4. CPPL
Answer: CPPL. Each letter moves 1 place forward: BOOK → CPPL.
हर अक्षर 1 स्थान आगे जाता है: BOOK → CPPL

Q4. If DOG is coded as WLT, how is SALT coded?

यदि DOG का कूट WLT है, तो SALT का कूट क्या होगा?

  1. IAPH
  2. GOZH
  3. TBMU
  4. HZOG
Answer: HZOG. Each letter is replaced by its opposite letter (A↔Z, B↔Y, C↔X …).
हर अक्षर को उसके विपरीत अक्षर से बदला गया है (A↔Z, B↔Y, C↔X …)।

Q5. If GOLD is written as DLOG, how is CAT written?

यदि GOLD को DLOG लिखा जाता है, तो CAT को कैसे लिखा जाएगा?

  1. UBD
  2. VCE
  3. CAT
  4. TAC
Answer: TAC. Write the word in reverse order.
शब्द को उल्टे क्रम में लिखें।

Q6. If FISH is written as HKUJ, how is CLOUD written in that code?

यदि FISH को HKUJ लिखा जाता है, तो उसी कूट में CLOUD को कैसे लिखा जाएगा?

  1. AJMSB
  2. FORXG
  3. FWQNE
  4. ENQWF
Answer: ENQWF. Each letter moves 2 places forward: CLOUD → ENQWF.
हर अक्षर 2 स्थान आगे जाता है: CLOUD → ENQWF

Q7. If SHIP is coded as HSRK, how is RAIN coded?

यदि SHIP का कूट HSRK है, तो RAIN का कूट क्या होगा?

  1. MRZI
  2. JASN
  3. SBJO
  4. IZRM
Answer: IZRM. Each letter is replaced by its opposite letter (A↔Z, B↔Y, C↔X …).
हर अक्षर को उसके विपरीत अक्षर से बदला गया है (A↔Z, B↔Y, C↔X …)।

Q8. If KING = 41 (sum of letter positions, A = 1 … Z = 26), then WIND = ?

यदि KING = 41 (अक्षरों के स्थान का योग, A = 1 … Z = 26), तो WIND = ?

  1. 48
  2. 50
  3. 53
  4. 51
Answer: 50. W(23) + I(9) + N(14) + D(4) = 50.
W(23) + I(9) + N(14) + D(4) = 50

Q9. In a certain code, EARTH is written as CYPRF. How is DANCE written in that code?

एक कूट भाषा में EARTH को CYPRF लिखा जाता है। उसी भाषा में DANCE को कैसे लिखेंगे?

  1. CZMBD
  2. FCPEG
  3. BYLAC
  4. CALYB
Answer: BYLAC. Each letter moves 2 places back (-2). DANCE → BYLAC.
हर अक्षर 2 स्थान पीछे जाता है (-2)। DANCE → BYLAC।

Q10. In a certain code, HEART is written as SVZIG. How is SMILE written in that code?

एक कूट भाषा में HEART को SVZIG लिखा जाता है। उसी भाषा में SMILE को कैसे लिखेंगे?

  1. HNROV
  2. VORNH
  3. TNJMF
  4. ELIMS
Answer: HNROV. Each letter is replaced by its opposite letter (A↔Z, B↔Y, C↔X …). SMILE → HNROV.
हर अक्षर को उसके विपरीत अक्षर से बदला गया है (A↔Z, B↔Y, C↔X …)। SMILE → HNROV।
