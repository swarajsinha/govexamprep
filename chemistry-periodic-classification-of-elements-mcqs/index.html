Sample Chemistry: Periodic Classification of Elements questions with answers

Q1. Which non-metal is a liquid at room temperature?

कमरे के ताप पर कौन-सी अधातु द्रव होती है?

  1. Iodine
  2. Chlorine
  3. Bromine
  4. Sulphur
Answer: Bromine. Bromine (Br) is the only liquid non-metal at room temperature.
ब्रोमीन (Br) कमरे के ताप पर एकमात्र द्रव अधातु है।

Q2. Elements in the same group have the same number of:

एक ही समूह के तत्वों में किसकी संख्या समान होती है?

  1. Protons
  2. Valence electrons
  3. Neutrons
  4. Shells
Answer: Valence electrons. That is why they show similar chemical properties.
इसी कारण उनके रासायनिक गुण समान होते हैं।

Q3. Silicon and germanium, which show properties of both metals and non-metals, are called:

सिलिकॉन और जर्मेनियम, जो धातु और अधातु दोनों के गुण दिखाते हैं, कहलाते हैं:

  1. Halogens
  2. Alkali metals
  3. Metalloids
  4. Noble gases
Answer: Metalloids. They are metalloids (semi-metals).
ये उपधातु (अर्धधातु) हैं।

Q4. Moving from left to right across a period, the atomic radius generally:

आवर्त में बाएँ से दाएँ जाने पर परमाणु त्रिज्या सामान्यतः:

  1. Stays the same
  2. Decreases
  3. First doubles, then halves
  4. Increases
Answer: Decreases. Nuclear charge increases and pulls electrons closer.
नाभिकीय आवेश बढ़ता है और इलेक्ट्रॉनों को पास खींचता है।

Q5. In which period is magnesium (Mg, atomic number 12) placed?

मैग्नीशियम (Mg, परमाणु संख्या 12) किस आवर्त में है?

  1. 3
  2. 5
  3. 2
  4. 6
Answer: 3. It has 3 shell(s) (2, 8, 2), so period 3.
इसके 3 कोश हैं (2, 8, 2), अतः आवर्त 3।

Q6. In which group of the modern periodic table is hydrogen (H, atomic number 1) placed?

आधुनिक आवर्त सारणी में हाइड्रोजन (H, परमाणु संख्या 1) किस समूह में है?

  1. 15
  2. 2
  3. 17
  4. 1
Answer: 1. Configuration 1: 1 valence electron(s) → group 1.
विन्यास 1: संयोजकता कोश में 1 इलेक्ट्रॉन → समूह 1।

Q7. Metallic character moving down a group generally:

समूह में नीचे जाने पर धात्विक गुण सामान्यतः:

  1. Increases
  2. Decreases
  3. Stays the same
  4. Disappears
Answer: Increases. Outer electrons are lost more easily down a group.
नीचे जाने पर बाहरी इलेक्ट्रॉन आसानी से निकलते हैं।

Q8. Which element has the symbol 'O'?

'O' किस तत्व का प्रतीक है?

  1. Chlorine
  2. Calcium
  3. Phosphorus
  4. Oxygen
Answer: Oxygen. 'O' is the symbol of oxygen.
'O' ऑक्सीजन का प्रतीक है।

Q9. In which period is beryllium (Be, atomic number 4) placed?

बेरिलियम (Be, परमाणु संख्या 4) किस आवर्त में है?

  1. 2
  2. 1
  3. 4
  4. 3
Answer: 2. It has 2 shell(s) (2, 2), so period 2.
इसके 2 कोश हैं (2, 2), अतः आवर्त 2।

Q10. In which group of the modern periodic table is silicon (Si, atomic number 14) placed?

आधुनिक आवर्त सारणी में सिलिकॉन (Si, परमाणु संख्या 14) किस समूह में है?

  1. 2
  2. 16
  3. 14
  4. 17
Answer: 14. Configuration 2, 8, 4: 4 valence electron(s) → group 14.
विन्यास 2, 8, 4: संयोजकता कोश में 4 इलेक्ट्रॉन → समूह 14।
